# XHTTP + CDN 搭建指南 (八)：拓展 - XHTTP H3

本拓展增加：

```text
xhttp+TLS+H3
上行 xhttp+TLS+H2 | 下行 xhttp+TLS+H3
上行 xhttp+TLS+H3 | 下行 xhttp+TLS+H2
```

复用已有的 Xray XHTTP 入站，不新增 Xray 入站。

## 1. 端口与文件

XHTTP H3 端口可输入 `1-65535`，默认 443，不能与 Hysteria2 使用相同端口。

服务端文件：

```text
/etc/nginx/nginx.conf
/usr/local/etc/xray/config.json
/etc/ssl/private/fullchain.cer
/etc/ssl/private/private.key
```

放行实际使用的 UDP 端口：

```text
实际选择的 UDP 端口
```

## 2. Nginx

编辑：

```text
/etc/nginx/nginx.conf
```

找到 CDN 域名的 `server` 块，在同一个块内加入 QUIC 监听。下面示例使用 UDP 443；使用其他端口时替换两处 `443`：

```nginx
server {
    listen       8003 ssl;
    listen       443 quic reuseport;
    http2        on;
    server_name  cdn.example.com;

    ssl_certificate /etc/ssl/private/fullchain.cer;
    ssl_certificate_key /etc/ssl/private/private.key;

    add_header Alt-Svc 'h3=":443"; ma=86400' always;

    location / {
        proxy_pass https://www.stanford.edu;
        proxy_ssl_server_name on;
        proxy_ssl_name www.stanford.edu;
        proxy_set_header Host www.stanford.edu;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-Host $host;
    }

    location /your-xhttp-path {
        grpc_pass 127.0.0.1:8001;
        grpc_set_header Host                  $host;
        grpc_set_header X-Real-IP             $real_client_ip;
        grpc_set_header Forwarded             $proxy_add_forwarded;
        grpc_set_header X-Forwarded-For       $proxy_add_x_forwarded_for;
        grpc_set_header X-Forwarded-Proto     $scheme;
    }
}
```

将：

```text
cdn.example.com       替换为已有 CDN 域名
/your-xhttp-path      替换为 Xray 127.0.0.1:8001 入站的 Path
```

使用本地静态页面时，只替换 `location /`：

```nginx
location / {
    root /var/www/dist/cdn.example.com;
    index index.html;
    try_files $uri $uri/ /index.html;
}
```

检查：

```bash
nginx -t
```

systemd 发行版：

```bash
systemctl restart nginx
```

Alpine Linux：

```sh
rc-service nginx restart
```

## 3. Xray

配置文件：

```text
/usr/local/etc/xray/config.json
```

继续使用已有入站：

```json
{
  "listen": "127.0.0.1",
  "port": 8001,
  "protocol": "vless",
  "streamSettings": {
    "network": "xhttp",
    "xhttpSettings": {
      "path": "/your-xhttp-path",
      "mode": "auto"
    }
  }
}
```

检查：

```bash
xray -test -config /usr/local/etc/xray/config.json
```

## 4. Mihomo

文件：

```text
/home/USERNAME/client-config-mihomo-full.yaml
/home/USERNAME/client-config-mihomo-nodes.yaml
```

### XHTTP H3

```yaml
  - name: xhttp+TLS+H3
    type: vless
    server: VPS_IP
    port: 443
    uuid: YOUR_UUID2
    udp: true
    flow: ""
    tls: true
    encryption: "YOUR_VLESS_ENCRYPTION"
    network: xhttp
    alpn:
      - h3
    servername: cdn.example.com
    client-fingerprint: chrome
    xhttp-opts:
      host: cdn.example.com
      path: /your-xhttp-path
      mode: auto
      reuse-settings:
        max-concurrency: "16-32"
        c-max-reuse-times: "0"
        h-max-reusable-secs: "1800-3000"
        h-keep-alive-period: 0
```

```yaml
      host: cdn.example.com
      path: /your-xhttp-path
      mode: auto
      reuse-settings:
        max-concurrency: "16-32"
        c-max-reuse-times: "0"
        h-max-reusable-secs: "1800-3000"
        h-keep-alive-period: 0
      download-settings:
        host: cdn.example.com
        path: /your-xhttp-path
        server: cdn.example.com
        port: 443
        tls: true
        alpn:
          - h2
        servername: cdn.example.com
        client-fingerprint: chrome
        reuse-settings:
          max-concurrency: "16-32"
          c-max-reuse-times: "0"
          h-max-reusable-secs: "1800-3000"
          h-keep-alive-period: 0
```

使用其他 UDP 端口时，只修改 H3 方向的 `port`。

使用 xpadding 时，外层写入：

```yaml
    xhttp-opts:
      x-padding-obfs-mode: true
      x-padding-key: "x_padding"
      x-padding-header: "Referer"
      x-padding-placement: "queryInHeader"
      x-padding-method: "tokenish"
```

存在 `download-settings` 时，下行也写入：

```yaml
      download-settings:
        x-padding-obfs-mode: true
        x-padding-key: "x_padding"
        x-padding-header: "Referer"
        x-padding-placement: "queryInHeader"
        x-padding-method: "tokenish"
```

选择 ECH 时，把 `ech-opts` 写入使用 TLS 的外层节点和 `download-settings`。

## 5. v2rayN / Xray

文件：

```text
/home/USERNAME/client-config.txt
```

XHTTP H3：

```text
vless://YOUR_UUID2@VPS_IP:443?encryption=YOUR_VLESS_ENCRYPTION&security=tls&sni=cdn.example.com&fp=chrome&alpn=h3&insecure=0&allowInsecure=0&type=xhttp&host=cdn.example.com&path=%2Fyour-xhttp-path&mode=auto#xhttp%2BTLS%2BH3
```

上行 H2 / 下行 H3 的外层参数使用：

```text
address = cdn.example.com
port = 443
alpn = h2
```

`extra`：

```json
{
  "downloadSettings": {
    "address": "VPS_IP",
    "port": 443,
    "network": "xhttp",
    "security": "tls",
    "tlsSettings": {
      "serverName": "cdn.example.com",
      "allowInsecure": false,
      "alpn": ["h3"],
      "fingerprint": "chrome"
    },
    "xhttpSettings": {
      "host": "cdn.example.com",
      "path": "/your-xhttp-path",
      "mode": "auto"
    }
  }
}
```

上行 H3 / 下行 H2 的外层参数使用：

```text
address = VPS_IP
port = 443
alpn = h3
```

`extra`：

```json
{
  "downloadSettings": {
    "address": "cdn.example.com",
    "port": 443,
    "network": "xhttp",
    "security": "tls",
    "tlsSettings": {
      "serverName": "cdn.example.com",
      "allowInsecure": false,
      "alpn": ["h2"],
      "fingerprint": "chrome"
    },
    "xhttpSettings": {
      "host": "cdn.example.com",
      "path": "/your-xhttp-path",
      "mode": "auto"
    }
  }
}
```

使用 xpadding 时，在外层 `xhttpSettings.extra` 和下行 `downloadSettings.xhttpSettings.extra` 中写入相同的 xpadding 配置。

选择 ECH 时，在外层 TLS 和下行 `downloadSettings.tlsSettings` 中写入 ECH 配置。
