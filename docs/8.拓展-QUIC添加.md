# XHTTP + CDN 搭建指南 (八)：拓展 - QUIC 添加

在已有配置上增加：

```text
VLESS + XHTTP + TLS + H3
Hysteria2
```

H2 直连不单独增加节点。将现有 `xhttp+TLS 双向 CDN` 节点的连接地址改成 VPS IP，同时保留 TLS、SNI、Host 和 `alpn: h2`，就是 XHTTP H2/TCP 直连。

XHTTP H3 节点使用 CDN 域名作为 SNI 和 Host。连接地址填写 VPS IP 时直连，改成 CDN 域名或 CDN IP 并使用端口 443 时经过 CDN。ECH 可选复用，默认关闭。

## 1. 工作方式

默认使用分开端口：

```text
XHTTP H3：客户端 → VPS UDP 443 → Nginx → Xray 127.0.0.1:8001
Hysteria2：客户端 → VPS UDP 8443 → Hysteria2
```

也可以在拓展脚本中选择共用端口：

```text
XHTTP H3：客户端 → VPS UDP 443 → Hysteria2 masquerade → Nginx 127.0.0.1:8003 → Xray 127.0.0.1:8001
Hysteria2：客户端 → VPS UDP 443 → Hysteria2
```

共用端口模式下，XHTTP H3 的公网 QUIC/TLS 由 Hysteria2 处理。

## 2. DNS 与防火墙

Reality 域名保持仅 DNS（灰色云朵），解析到 VPS。

默认放行：

```text
UDP 443
UDP 8443
```

修改默认端口后，放行实际使用的 UDP 端口。

## 3. 证书

两个节点复用：

```text
/etc/ssl/private/fullchain.cer
/etc/ssl/private/private.key
```

检查证书：

```bash
openssl x509 -in /etc/ssl/private/fullchain.cer -noout -ext subjectAltName
```

## 4. VLESS + XHTTP + TLS + H3 服务端

XHTTP H3 复用 `/usr/local/etc/xray/config.json` 中已有的 `127.0.0.1:8001` XHTTP 入站，不增加新的 Xray 入站。公网 HTTP/3 由 Nginx 接收。

编辑 `/etc/nginx/nginx.conf`，找到 Reality 域名的 `server` 块，在 `server_name` 后增加 XHTTP 转发：

```nginx
listen 443 quic reuseport;
add_header Alt-Svc 'h3=":443"; ma=86400' always;

location /your-existing-xhttp-path {
    grpc_pass 127.0.0.1:8001;
    grpc_set_header Host $host;
    grpc_set_header X-Real-IP $real_client_ip;
    grpc_set_header Forwarded $proxy_add_forwarded;
    grpc_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    grpc_set_header X-Forwarded-Proto $scheme;
}
```

将 `/your-existing-xhttp-path` 改成 `/usr/local/etc/xray/config.json` 中 `127.0.0.1:8001` 入站使用的 XHTTP Path。原有 `location /` 保持不变。

## 5. Hysteria2 服务端

### Debian / Ubuntu

```bash
HYSTERIA_USER=root bash <(curl -fsSL https://get.hy2.sh/)
```

### Alpine Linux

`x86_64`：

```sh
curl -fL https://github.com/apernet/hysteria/releases/latest/download/hysteria-linux-amd64 -o /usr/local/bin/hysteria
chmod +x /usr/local/bin/hysteria
```

`aarch64`：

```sh
curl -fL https://github.com/apernet/hysteria/releases/latest/download/hysteria-linux-arm64 -o /usr/local/bin/hysteria
chmod +x /usr/local/bin/hysteria
```

创建 `/etc/init.d/hysteria-server`：

```sh
cat > /etc/init.d/hysteria-server <<'EOF'
#!/sbin/openrc-run

name="hysteria-server"
description="Hysteria2 Server"
command="/usr/local/bin/hysteria"
command_args="server --config /etc/hysteria/config.yaml"
command_background=true
pidfile="/run/hysteria-server.pid"
output_log="/var/log/hysteria-server.log"
error_log="/var/log/hysteria-server.log"

depend() {
    need net
}
EOF

chmod +x /etc/init.d/hysteria-server
rc-update add hysteria-server default
```

创建配置目录并编辑 `/etc/hysteria/config.yaml`：

```bash
mkdir -p /etc/hysteria
vi /etc/hysteria/config.yaml
```

Hysteria2 默认使用 UDP 8443：

```yaml
listen: :8443

tls:
  cert: /etc/ssl/private/fullchain.cer
  key: /etc/ssl/private/private.key

auth:
  type: password
  password: YOUR_HY2_PASSWORD

masquerade:
  type: proxy
  proxy:
    url: https://127.0.0.1:8003
    rewriteHost: false
    insecure: true
```

Hysteria2 的普通 HTTP/3 请求反向代理到 Nginx，由 Reality 域名的 `location /` 返回反向代理网站或本地静态页面。选择共用端口模式时，将 `listen` 改成 XHTTP H3 使用的端口，并删除 Nginx 中的 `listen ... quic` 和 `Alt-Svc`。

## 6. Mihomo 客户端配置

文件：

```text
/home/USERNAME/client-config-mihomo-full.yaml
/home/USERNAME/client-config-mihomo-nodes.yaml
```

```yaml
  - name: vless+xhttp+tls+h3 直连
    type: vless
    server: VPS_IP
    port: 443
    uuid: YOUR_UUID2
    udp: true
    flow: ""
    tls: true
    encryption: "YOUR_VLESSENC_ENCRYPTION"
    network: xhttp
    alpn:
      - h3
    servername: cdn.example.com
    client-fingerprint: chrome
    xhttp-opts:
      host: cdn.example.com
      path: /your-existing-xhttp-path
      mode: auto

  - name: hysteria2 直连
    type: hysteria2
    server: VPS_IP
    port: 8443
    password: "YOUR_HY2_PASSWORD"
    sni: reality.example.com
    alpn:
      - h3
```



## 8. 检查与重启

检查配置：

```bash
nginx -t
xray -test -config /usr/local/etc/xray/config.json
```

Debian / Ubuntu：

```bash
systemctl enable --now hysteria-server.service
systemctl restart nginx
ss -lnup | grep -E ':(443|8443)\b'
```

Alpine Linux：

```sh
rc-service hysteria-server restart
rc-service nginx restart
ss -lnup | grep -E ':(443|8443)\b'
```
