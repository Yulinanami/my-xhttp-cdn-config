# XHTTP + CDN 搭建指南 (八)：拓展 - 常用节点

本文档用于在已有 XHTTP + CDN 配置基础上，增加两个常用节点：

```text
VLESS + WebSocket + TLS + CDN
Hysteria2 直连
```

前提：你已经按前面的文档完成基础配置，并且 Reality 域名、CDN 域名和证书均可正常使用。

---

## 1. 工作方式

VLESS + WebSocket + TLS 节点复用原有 CDN 域名和证书：

```text
客户端 → CDN:443 → VPS TCP 443 → Xray Reality fallback → Nginx 8003 → Xray WebSocket 入站 8002
```

Hysteria2 默认使用 UDP 443 直连 VPS；如果 VPS 上游不允许 UDP 443，也可以改用其他已放行的 UDP 端口：

```text
客户端 → VPS IP → VPS UDP 端口 → Hysteria2
```

默认情况下，TCP 443 与 UDP 443 是不同的监听协议，因此可以同时使用。

---

## 2. DNS 与防火墙

继续使用原来的两个域名：

- CDN 域名：开启 CDN 代理（橙色云朵），供 VLESS + WebSocket + TLS 使用。
- Reality 域名：保持仅 DNS（灰色云朵），供 Hysteria2 直连使用。

Hysteria2 需要同时在系统防火墙和 VPS 服务商安全组放行实际使用的 UDP 端口：

```text
UDP 443（或脚本中填写的其他 UDP 端口）
```

---

## 3. 证书

两个节点复用主配置已经申请的证书：

```text
/etc/ssl/private/fullchain.cer
/etc/ssl/private/private.key
```

证书需要包含 CDN 域名和 Reality 域名。可以用下面的命令检查：

```bash
openssl x509 -in /etc/ssl/private/fullchain.cer -noout -ext subjectAltName
```

## 4. VLESS + WebSocket 服务端

在 Xray 的 `inbounds` 中增加一个只监听本机的 WebSocket 入站：

```json
{
  "tag": "vless-ws-cdn",
  "listen": "127.0.0.1",
  "port": 8002,
  "protocol": "vless",
  "settings": {
    "clients": [
      {
        "id": "YOUR_UUID2",
        "level": 0
      }
    ],
    "decryption": "none"
  },
  "streamSettings": {
    "network": "ws",
    "wsSettings": {
      "path": "/your-ws-path"
    }
  }
}
```

在原 CDN 域名的 Nginx `server` 块中增加 WebSocket 转发：

```nginx
location = /your-ws-path {
    if ($http_upgrade != "websocket") {
        return 404;
    }

    proxy_pass http://127.0.0.1:8002;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $real_client_ip;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

WebSocket 路径不能与现有 XHTTP 路径相同。

## 5. Hysteria2 服务端

一键扩展脚本会自动安装 Hysteria2。手动搭建时，在使用 systemd 的 Debian / Ubuntu 上执行官方安装指令：

```bash
HYSTERIA_USER=root bash <(curl -fsSL https://get.hy2.sh/)
```

这里让 Hysteria2 以 root 用户运行，是为了读取主配置生成在 `/etc/ssl/private/` 下的证书。

安装完成后，创建 `/etc/hysteria/config.yaml`：

```yaml
listen: :443

tls:
  cert: /etc/ssl/private/fullchain.cer
  key: /etc/ssl/private/private.key

auth:
  type: password
  password: YOUR_HY2_PASSWORD

masquerade:
  type: proxy
  proxy:
    url: https://www.stanford.edu
    rewriteHost: true
```

启用并立即启动 Hysteria2：

```bash
systemctl enable --now hysteria-server.service
```

检查服务状态和 UDP 443 监听：

```bash
systemctl status hysteria-server.service --no-pager
ss -ulnp | grep ':443'
```

如果服务启动失败，查看日志：

```bash
journalctl --no-pager -e -u hysteria-server.service
```

## 6. Mihomo 客户端配置

### VLESS + WebSocket + TLS + CDN

```yaml
  - name: vless+ws+tls+CDN
    type: vless
    server: cdn.example.com
    port: 443
    uuid: YOUR_UUID2
    udp: true
    flow: ""
    tls: true
    network: ws
    servername: cdn.example.com
    client-fingerprint: chrome
    ws-opts:
      path: /your-ws-path
      headers:
        Host: cdn.example.com
```

如果原 CDN 节点启用了 ECH，把原节点的 `ech-opts` 同步到这个节点。

### Hysteria2 直连

```yaml
  - name: hysteria2 直连
    type: hysteria2
    server: VPS_IP
    port: 443
    password: "YOUR_HY2_PASSWORD"
    sni: reality.example.com
    alpn:
      - h3
```

## 7. v2rayN / Shadowrocket 客户端配置

VLESS + WebSocket + TLS 分享链接：

```text
vless://YOUR_UUID2@cdn.example.com:443?encryption=none&security=tls&sni=cdn.example.com&fp=chrome&insecure=0&allowInsecure=0&type=ws&host=cdn.example.com&path=%2Fyour-ws-path#vless%2Bws%2Btls%2BCDN
```

Hysteria2 分享链接：

```text
hysteria2://YOUR_HY2_PASSWORD@VPS_IP:443/?sni=reality.example.com&insecure=0#hysteria2%20%E7%9B%B4%E8%BF%9E
```

---

## 8. 检查与重启

修改完成后检查并重启服务：

```bash
nginx -t
xray -test -config /usr/local/etc/xray/config.json
systemctl restart nginx
systemctl restart xray
systemctl restart hysteria-server
```

如果 Hysteria2 无法连接，先确认 VPS 服务商是否允许 UDP 443。系统防火墙放行并不代表服务商上游网络一定允许该端口。
