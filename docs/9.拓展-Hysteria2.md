# XHTTP + CDN 搭建指南 (九)：拓展 - Hysteria2

Hysteria2 使用独立 UDP 端口和已有证书，普通 HTTP/3 请求反向代理到 Nginx 回落页面。

## 1. 端口与文件

Hysteria2 端口可输入 `1-65535`，默认 8443，不能与 XHTTP H3 使用相同端口。

服务端文件：

```text
/usr/local/bin/hysteria
/etc/hysteria/config.yaml
/etc/ssl/private/fullchain.cer
/etc/ssl/private/private.key
```

默认使用 UDP 8443，可以自行修改，需要云防火墙和系统防火墙放行对应的 UDP 端口。

## 2. 安装

### systemd 发行版

```bash
HYSTERIA_USER=root bash <(curl -fsSL https://get.hy2.sh/)
```

## 3. 配置

新建配置目录并修改配置：

```bash
mkdir -p /etc/hysteria
vi /etc/hysteria/config.yaml
```

```yaml
listen: :8443

tls:
  cert: /etc/ssl/private/fullchain.cer
  key: /etc/ssl/private/private.key

auth:
  type: password
  password: YOUR_HY2_PASSWORD

masquerade:
  type: proxy
  proxy:
    url: https://127.0.0.1:8003
    rewriteHost: false
    insecure: true
```

Hysteria2 客户端的 SNI 使用已有 Reality 域名。Nginx 的 Reality 域名 `server` 块决定回落页面。

## 4. 服务

### systemd 发行版

服务文件：

```text
/etc/systemd/system/hysteria-server.service
```

```ini
[Unit]
Description=Hysteria2 Server
After=network.target

[Service]
ExecStart=/usr/local/bin/hysteria server --config /etc/hysteria/config.yaml
Restart=on-failure
RestartSec=5
LimitNOFILE=1048576

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now hysteria-server
```

## 5. 证书续期

systemd 发行版：

```bash
acme.sh --install-cert -d reality.example.com --ecc \
  --key-file /etc/ssl/private/private.key \
  --fullchain-file /etc/ssl/private/fullchain.cer \
  --reloadcmd "systemctl restart hysteria-server; systemctl restart nginx"
```

## 6. Mihomo

文件：

```text
/home/USERNAME/client-config-mihomo-full.yaml
/home/USERNAME/client-config-mihomo-nodes.yaml
```

```yaml
  - name: hysteria2 直连
    type: hysteria2
    server: VPS_IP
    port: 8443
    password: "YOUR_HY2_PASSWORD"
    sni: reality.example.com
    alpn:
      - h3
```
